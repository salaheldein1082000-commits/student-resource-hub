# Pearson Unit 1 criterion wording

Pearson's official BTEC International Level 3 IT specification identifies Unit 1 as **Information Technology Systems — Strategy, Management and Infrastructure** and lists Learning Aim A as exploring how IT infrastructure meets the needs of organisations and their stakeholders. The assignment-to-task grouping below follows the user's prompt; it is not inferred from Pearson's specification.

| Code | Task | Official description |
| --- | --- | --- |
| A.P1 | Task 1 | Explain ways in which software can meet the needs of an organisation and its stakeholders. |
| A.P2 | Task 1 | Explain ways in which hardware can meet the needs of an organisation and its stakeholders. |
| A.P3 | Task 1 | Explain ways in which the use of data connections and networks can meet the needs of an organisation and its stakeholders. |
| A.M1 | Task 2 | Analyse how IT infrastructure can impact an organisation and its stakeholders. |
| A.D1 | Task 2 | Evaluate how IT infrastructure can impact an organisation and its stakeholders. |

The official Pearson course-materials page lists the qualification specification and course materials. The criterion text and Unit 1 learning aim above were checked in the specification PDF.
